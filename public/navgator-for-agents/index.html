NAVgator for Agents

NAVgator exposes static pages, downloadable data files, and public JSON endpoints so agents can inspect and cite ownership-token treasury data without driving the JavaScript terminal.

How to Query

GET https://navgator.xyz/api/summary
GET https://navgator.xyz/api/projects
GET https://navgator.xyz/api/projects/umbra/nav
GET https://navgator.xyz/api/projects/umbra/treasury
GET https://navgator.xyz/api/projects/umbra/proposals
GET https://navgator.xyz/api/projects/umbra/risk

Endpoints

EndpointUse
/api/summaryCompact overview with project count, active tokens, premiums, discounts, stale tokens, and health summary.
/api/projectsDiscover projects, slugs, static URLs, and endpoint URLs.
/api/projects/:slugRead baseline metadata, wallet addresses, definitions, and source notes.
/api/projects/:slug/navRead latest stored NAV, spot, treasury, market cap, and supply fields.
/api/projects/:slug/treasuryRead treasury total and component metrics.
/api/projects/:slug/proposalsRead proposal counts and indexed proposal rows.
/api/projects/:slug/riskRead rule-based risk flags for stale data, missing inputs, extreme premium/discount, and proposal activity.
/api/marketsRead market rows derived from latest snapshots.
/api/watchlistRead major projects with static research pages.
/api/snapshots/latestRead latest publishable snapshots across projects.

Data Files

  • /data/projects.json
  • /data/treasuries.json
  • /data/nav-snapshots.csv
  • /data/proposals.json

Citation

Cite the exact endpoint or static page plus the response timestamp. For NAV and treasury metrics, include snapshot_time or metric updated_at. Treat wallet ownership and effective supply rules as NAVgator assumptions unless separately verified.

Rate Limits

The public agent endpoints are cacheable read-only surfaces. Avoid polling faster than the cache headers indicate. Prefer one project endpoint and one NAV endpoint over scraping the terminal HTML.
